# Как редактировать сайт

Запуск: открой Git Bash и введи
    cd ~/Documents/mysite
    hugo server
Потом открой в браузере http://localhost:1313 — изменения видны сразу после сохранения файла.

## Что где лежит

| Хочу изменить | Файл |
|---|---|
| Казино: названия, рейтинги, бонусы, плюсы | data/casinos.yaml |
| Плитки «Top Bonuses» | data/bonuses.yaml |
| Вопросы FAQ | data/faq.yaml |
| Блок «How We Rate» | data/criteria.yaml |
| Заголовок и текст первого экрана | content/_index.md |
| Текст обзора казино | content/reviews/<название>.md |
| Название сайта, акция сверху, автор, текст подвала, меню | hugo.toml |
| Цвета | themes/casino-review/assets/css/main.css (самый верх файла) |

## Как добавить новое казино
1. В data/casinos.yaml скопируй блок одного казино (от "- slug:" до "url:") и поменяй значения.
2. В папке content/reviews скопируй любой файл обзора, переименуй (например, newcasino.md)
   и в нём поменяй title и casino (casino должен совпадать со slug из шага 1).

## Важно
- В .yaml-файлах важны отступы (пробелы). Не используй Tab.
- Ссылки на казино (url: "#") замени на настоящие.
